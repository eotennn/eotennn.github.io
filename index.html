Müzikleri keşfet

What the tracker does

1 · Import records

Read selected metadata exports (CSV) locally in your browser, and use the separately installed desktop application for supported account exports and authorized APIs.

2 · Identify songs

Compare song titles, releases, video titles and dates while keeping different recordings and versions distinct. A title match is not proof of matching audio.

3 · Review coverage

Inspect the release/platform matrix. Missing or inaccessible API data is marked as unknown, not proof that a song is unavailable.

Available browser tool

The local CSV viewer lets you choose a file on your own device and search your records. The browser does not upload that file to our servers. This page itself does not log in to TikTok or pull account data.

Development status: The separate Windows desktop tracker has local archive imports and some external API integrations. The public music showcase shows a safe subset of published links; live account logins remain in the separate desktop application.

Privacy and user control

Import only your own files or content you are authorized to access. Local exports can contain sensitive information unrelated to music; only music/video fields should be used for an inventory.
