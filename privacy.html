Privacy Policy

Effective date: October 28, 2026 · Application: EoTeN Music Tracker · Operator: EoTeN AI Music Production

1. Scope and purpose

EoTeN Music Tracker helps authorized users organize music releases and social media video metadata. This policy describes the public information website, the browser-based CSV viewer, and the separate local desktop tracking application. These components may have different capabilities.

2. Information processed

When the user supplies or authorizes it, the local software may process song titles, release dates, album and track identifiers, video titles, captions, links, posting dates, and matching status. The desktop program may read files the user voluntarily imports and use configured Spotify or YouTube API credentials to request metadata. TikTok Login Kit and Display API integration is planned; when implemented and authorized, it is intended to request basic account profile data and the user's public video list within approved scopes.

Account export files can also contain unrelated personal data, such as messages or viewing history. The inventory is designed to use relevant publishing records, not to publish those unrelated fields.

3. Browser CSV viewer

The CSV viewer on this site reads a selected file in your browser's memory. The site does not intentionally transmit the contents of that file to an EoTeN-operated server. The viewer does not store files in browser local storage or cookies. Closing or refreshing the page clears the current import.

4. Local desktop storage

The separately installed desktop program may keep copies of imported publication metadata, exported reports, and configuration files on the user's device. Users control these local files and should protect API secrets and account archives. At present, the public website does not provide a remote account service or cloud synchronization.

5. TikTok authorization and permissions

Any future live TikTok connection will require the user to explicitly authorize requested permissions. The intended scopes are user.info.basic and video.list, subject to TikTok review and approval. We will not represent TikTok connectivity as active before implementation and authorization. Users may revoke an authorized app in their TikTok settings.

6. Purposes and sharing

The intended purpose is to display an organized record of songs, videos, platforms, links and matching confidence. EoTeN does not sell imported publication data. Information is shared with external platforms only when a user explicitly uses their respective APIs or follows their links. The website does not operate advertising or behavioral analytics scripts.

7. Hosting and third parties

The public informational pages are hosted by GitHub Pages. GitHub may process connection details such as IP addresses for hosting and security in accordance with GitHub's privacy statement. Visits to external links are governed by those services' policies.

8. Retention, access and deletion

The local program retains exported metadata until its user removes the relevant files or replaces the stored inventory. You may delete local exports and the program's data and configuration files from your own device. For help with any information you believe the operator holds, contact the address below. Deleting local reports does not delete content hosted on Spotify, TikTok, Instagram or YouTube.

9. Security and limitations

The user should keep secrets, downloaded archives and private files out of publicly accessible repositories. Local storage is not a substitute for full-disk encryption or secure backup. No information system can guarantee absolute security.
