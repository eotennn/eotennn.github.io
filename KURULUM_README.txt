IMPORTANT TIKTOK NOTES:

  and upload the provided verification file to the public site root; avoid any claims
  that GitHub Pages automatically verifies ownership with TikTok.
- A working public site plus legal pages DOES NOT guarantee TikTok API review approval.
  TikTok requires an actually functioning product, review rationale and demo, and
  warns against purely private/personal use and undeveloped apps.
- This site does not implement TikTok Login Kit or Display API. An OAuth implementation
  and approved scopes are needed to access TikTok live data; never put secrets here.
